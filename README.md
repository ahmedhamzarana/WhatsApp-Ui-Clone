# 📱 WhatsApp UI Clone (Flutter)

A clean and simple WhatsApp User Interface clone built using Flutter.\
This project focuses on designing the WhatsApp front-end (UI only)
including Chats, Status, Calls & Camera sections.

------------------------------------------------------------------------

## 📁 Project Structure


------------------------------------------------------------------------

## 🎯 Features

-   WhatsApp-style **TabBar**: Camera, Chats, Status, Calls\
-   Fully responsive & clean UI\
-   Custom chat list tiles\
-   Calls list UI\
-   Reusable custom widgets\
-   Organized folder structure

------------------------------------------------------------------------

## 🧪 Screens UI Implemented

-   **Chat List Screen**\
-   **Chat Detail UI (Bubble Style)**\
-   **Calls List UI**\

## 🚀 Getting Started

### 1️⃣ Clone the Repository

``` bash
git clone https://github.com/ahmedhamzarana/WhatsApp-Ui-Clone.git
```

### 2️⃣ Navigate to Project

``` bash
cd WhatsApp-Ui-Clone
```

### 3️⃣ Install Dependencies

``` bash
flutter pub get
```

### 4️⃣ Run the App

``` bash
flutter run
```
